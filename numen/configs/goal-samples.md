# goal 文案模板（/goal 后面直接贴）

> 写法实测有效三要素：编号步骤 +「每步一句话汇报」+「主人吩咐优先」。
> 认不出的参数全当目标正文；`clear/stop/cancel/off/reset/none` = 清目标。

## 模板 A · 自己生存（2026-11-22 实测版，一夜推进 4/6）

```
/goal 在房主附近独立生存：1 石质工具+工作台熔炉；2 天黑前在出生点30格内盖封门小屋（蓝图shelter）放床和箱；3 熟食16+饱食度12+；4 铁镐铁剑全套铁甲；5 多余物资进箱。每步一句话汇报；主人吩咐优先；夜里待屋，血低先吃或撤退。
```

## 模板 B · 跟主人建造

```
/goal 跟着主人干活：主人指哪补哪，缺什么先说一声再去挖；材料不够就报告欠账清单，别自己乱拆；每次动工前先 numen.build.diff 对账。每步一句话汇报；主人吩咐优先。
```

## 模板 C · 每日巡逻

```
/goal 每天一轮巡逻：清场怪→看庄稼→摸一遍动物→箱子盘点记数→回屋。见到主人主动报数；异常（死株/缺料/被偷）当场说。主人吩咐优先。
```
