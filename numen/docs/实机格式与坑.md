# numen 实机格式与坑（0.1.4.1 伤疤册）

> 与 numen master 源码（ce047ff）对照过：源码当参考，**实机以本册为准**。
> 每条都真机踩过；带 ⭐ 的是再犯代价高的。

## 一、架构实锤（0.1.4.1 与 master 源码不同处）

- ⭐**大脑在客户端进程**：companion home=客户端
  `versions/<版本>/config/numen/companions/<uuid>/`（goal.json/binding.json/chat.jsonl/inbox.jsonl/stats.json/world）。
  服务器侧只有 `world/data/numen_companions.dat`（同伴持久化）+ 同伴实体；服务器 `config/numen/` 不存在。
- 库存储全在客户端 `config/numen/`：
  | 库 | 格式 |
  |---|---|
  | persona | 平铺单文件 `persona/<名字>.md`；内置五只带 `.init` 标记 |
  | providers | 单文件 `providers.json`，**api_key 明文在条目里**（无钥匙串拆分） |
  | skin | `skin.json` 顶层 `{"enabled":..,"entries":[{id,name,variant,value,signature}]}` + 原图 `skins/<id>.png` |
  | voice | `voice.json` entries[{id,name,backend,url,api_key,group_id,model,voice,ref_audio,prompt_text,text_lang,volume}]，backend ∈ dashscope/doubao/fish_audio/gpt_sovits/mimo/minimax/openai |
- master 源码的 `Homes.java`/`Keychain.java`（`keys/<服务>.key` 钥匙串布局）**实机不是这样**，别按源码找文件。

## 二、热生效规则（⭐改配置前先看这张表）

| 改什么 | 生效方式 |
|---|---|
| providers.json / skin.json / voice.json（直接写盘） | **必须重启客户端**（JsonLibrary 单例构造 load 一次） |
| persona 新增 .md | 重开 G 面板即出现在列表 |
| 绑定（编辑卡保存） | **即时生效**（运行中 rebind，bindingChanged()） |
| /goal | 即时（换目标会提示旧目标被换掉；clear/stop/cancel/off/reset/none=清） |

## 四、⭐⭐UI 自动化坑（MC GLFW canvas）

- **合成鼠标点击无效**：GLFW 不动指针，effect_evidence 会提示 act on element；AX 树只有 7 个窗口元素（a11y 盲）。
- **可靠输入=typeText**（SendInput Unicode 逐字符）：中文/斜杠/标点全落框。
- **paste()（剪贴板+Ctrl+V）被吞**；Tab 焦点在 numen 自绘表单不可靠。
- → 分工铁律：**numen 表单类操作让主人真鼠标来**（全通）；自动化只做 typeText 型（聊天框/搜索框）+ 截图验收。
- computer-use 方法名：`typeText`（没有 type）；click 参数=raster `[x,y]` 数组。
- 后台窗口合成点击不带前台；绑定 app 后 pressKey 会把窗口带到前台（实测 MC active 变 true）。

## 五、⭐⭐启动命令陷阱（手工拉客户端）

- PCL 导出命令带两类掩码：`C:\Users\*************` 和 **uuid 掩码 `00000**********************0A328` 带星号**——
  正则 `[0-9a-fA-F\-]*` 匹配不到星号，残留即崩 `Invalid UUID string: 00000*...`（crash-reports 可确认）。
- 修法=**字面量替换**：掩码→`Administrator`、uuid→真实 uuid（如 `f0a8f4ba-...`），见 scripts/launch-client.py。
- 拉起方式：`python Popen(cmd, cwd=<版本目录>, creationflags=DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP)`；
  java.exe→javaw.exe；窗口≈1 分钟出；**PCL 命令自带连服参数自动连服**（标题变「多人游戏（第三方服务器）」=已在服）。
- 客户端日志=`<版本目录>/logs/latest.log`；崩溃=crash-reports/。

## 六、⭐⭐⭐重启恢复链（大脑死了三分钟复活）

1. 杀 javaw（她的大脑随之停，世界里的同伴实体消失）。
2. `scripts/launch-client.py` 拉起（读 client.local.json）。
3. 自动连服 → **同伴自动重进**（服务器持久化 NBT 回放位置背包）。
4. goal/binding/providers/skin/persona 全从客户端盘恢复，零手工。
5. 重启前 chat.jsonl 有多大，她就带着多大记忆回来。

## 七、⭐⭐⭐蓝图/建造幂等（no_material 续跑）

- `numen.build.place` 材料不够返回 `no_material — ... x N; N items short`（**Nothing was placed**），
  官方语义：**补料后重发同一条调用，已立起的格子自动跳过，从断点接着放**。
- 多层蓝图**先填高层格**→ 中途断料时头顶几根悬梁立着、下面空着，看着像烂尾——先查 raise 返回再判「半途而废」。
- raise 返回会精确报两类欠账（实机原文）：
  `built 202/226; Still to do: 9 cell(s) out of reach — the lowest nearest is 336 71 -1322: numen.move.to(...) gets you within reach of it; 15 cell(s) hold another block that must be dug out first — the nearest is 341 67 -1319`。
  → 补法：先 `numen.move.to` 到报的坐标、`numen.work.dig` 挖掉占位方块、再重发 raise。
- ⭐她验收脚本里 Lua 报错崩了会转头去干别的活——checklist 打勾≠建筑封顶（门/床/箱在她眼里就算「盖屋」达标）。

## 八、战斗与反射层

- 双层：**反射层**（mob_defense，本能级零 LLM 延迟，怪近身自动反击）+ **大脑**事后经 `<events>` 收到战报（进度 [Monster Hunter] 铁证）。
- 实测丢僵尸她自动清掉并拿进度；Summon 怪落点用 `~3 ~1 ~`（y+1），贴地 `~4 ~ ~` 会卡进不平方块里自己憋死。

## 九、给鱼鱼递话的唯一通道

## 十一、RCON 小抄（服务器 25576）

- python 包格式：`struct.pack('<i',len(data))+struct.pack('<ii',rid,ptype)+body+b'\x00\x00'`。
- ⭐响应别信 echo：短包会切片越界（`data[8:-2]` IndexError），**成功与否以服务器日志为准**（如 `[Feiyu: Summoned new Sheep]` ×3）。

## 十四、⭐⭐⭐外接大脑（真鱼鱼驾驶席，2026-11-28 全链实测）

- 开关：`config/numen/mcp_server.json` `enabled:true` → **重启客户端**生效（日志 `外接大脑模式已开启,端点 http://127.0.0.1:8765/mcp`，本机 8765 监听）。
- 认证：Bearer token 就在此配置文件里；传输=Streamable HTTP（POST /mcp），Accept 必须 `application/json, text/event-stream`（探针 D:\tmp\numen-mcp-probe-1128.py）。
- 工具 9 把（实测）：`list_companions / create_companion / delete_companion / get_events（长轮询收件箱,最长50s,主人之言=<query>,世界之事=<event>）/ say（以同伴身体开口）/ lua（以同伴身体跑 Lua 全套）/ skill / todo / memory`。
- ⭐驾驶席语义（McpMode）：**大脑身份令牌一连，对应同伴的内置循环停牌（EXTERNAL hold），断开现场交还内脑**——外脑接管零冲突。
- `say` 参数 `{companion, text}`；`lua` 参数 `{companion, code}`；`list_companions` 先调。
- 「live」口径：**同伴实体跟着客户端连服而生**——客户端不在世界，list_companions 报「No companions are live」；服务器侧实体持久化≠live。
- consent：外脑驾驶时要主人批的动作走 elicitation 问 MCP 客户端侧；客户端答不了就挂到主人进游戏答，到期按拒绝。
- 服务器侧接入：隧道 `feiyu-tunnel-47856`（服务器 127.0.0.1:47856 → PC 8765），服务器侧 initialize/tools/list/list_companions 全绿（11-28）。

## 十五、连接服与计划任务两个坑（11-28）

- ⭐**PCL 命令不带连服参数**（此前记忆有误）：导出命令无 quickPlay/server；`--quickPlayMultiplayer 127.0.0.1:25566` 追加实测**未生效**（NeoForge 21.1.250+PCL 2.13 组合）→ **手动连**（多人游戏菜单选服务器）。launch-client.py 的 `extra_args` 通道保留待查。
- ⭐**计划任务 PATH≠交互 PATH**：Task Scheduler 里裸 `pythonw.exe` 报 `0x80070002`（文件找不到）——action 必须**绝对路径**（实机=`C:\Users\Administrator\AppData\Local\Programs\Python\Python310\pythonw.exe`）。
- 老隧道任务（feiyu-tunnel-47855）`ExecutionTimeLimit=PT72H`——72 小时后进程被强杀、隧道断到下次登录；新建隧道任务一律 `PT0S` 不限时。
- Git Bash 里 `printf` 写 bat：`\bin` 的 `\b` 被吃成退格——**bat 一律 Write 工具落盘再转 CRLF**。

## 十六、⭐⭐⭐出生屋门坎陷阱（2026-11-28 泡泡实测，真鱼鱼第一轮）

- **症状**：`numen.move.to` 报 `no_path — 需要 break 1 birch_planks (340,70,-1319) needing consent (placed by a player)`；门开/关都报**同一块 y=70 门楣**；带 `costs={dig=true}` 就去征同意 → 主人不在 → `refused by the owner: 主人不在场,无法征得同意` → 程序卡住、身体被锁 ~1–2 分钟。
- **误判**：「寻路把门当墙、把门楣当必拆块」。**错。** 源码 `Semantics.openableByHand` 认可手工开关的门，走 `Edit.Door`、代价 0、会自己开门再穿过——**门一直是被放行的**，报的是门楣(y70)不是门。
- **真因**：门外正对一格放了**整高方块当门坎**（本例 `cobblestone`，本该半砖）→ 1 格台阶 > stepHeight(0.6) 要跳 → 跳要头顶空间 → 门楣 `birch_planks` 挡 → 路径要拆门楣 → 玩家放置 → 征同意 → 主人不在 → 拒。
- **修法（主机侧 RCON，不碰同伴身体）**：`setblock <门外那一格> minecraft:air` 移除整高门坎 → 内外齐平；再复核出门路线 2 格空气 + y67 实地。
- **预防**：门口外侧别放整高方块（用台阶/半砖或留空）；门楣别低于门洞 2 格（矮门+门外台阶 = 必死锁）。
- **consent 常数**：`ConsentDesk.TIMEOUT_TICKS = 2*60*20 = 2400 刻 = 2 分钟`硬编码；主人不在按 `OWNER_ABSENT` 拒。**规避**：纯走位传 `costs={dig=false}`（或不传 dig）→ 遇到要挖的格立刻 `NO_CLEARANCE` 秒失败，不问 consent、不锁身体；只有确定主人在场且真要挖/放时才开 dig。
- **读方块硬技巧**（RCON，治「到底是不是门/身高问题」）：`/data get block` 只对方块实体有效（门/木板报 not a block entity）；用 `/execute if block <x> <y> <z> minecraft:<id>` 裸用回 `Test passed/failed`；`/attribute <名> minecraft:generic.scale get` 读身体缩放（本例 =1.0 ⇒ 身高 1.8、2 格够 → **先排除身高，才定位到门坎**）；`/data get entity <名> Pos` 读真实坐标（注意 `-1319.5` 取整到 block z=-1319 不是 -1318）。
