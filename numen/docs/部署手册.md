# numen 车道部署手册（从零到她开口）

> 实机版本：numen-neoforge-1.21.1-0.1.4.1 ｜ MC 1.21.1 NeoForge ｜ 2026-11-22 全流程真机验收
> 本手册每一步都踩过并验收过；括号里是当时踩的坑。

## 0. 前置

| 件 | 说明 |
|---|---|
| NeoForge 1.21.1 服务器 | 本模块跑在 `G:\minecraft-ai\neoforge-server`（25566） |
| PCL 客户端 1.21.1-NeoForge_Cam | 版本目录=大脑的家 |
| numen mod jar | **服务器和客户端都装**，同名同版本（0.1.4.1） |
| ysm.jar | 两侧都装（要换 YSM 模型的话） |
| OpenAI 兼容 LLM 端点 | 自家 agent2api `http://127.0.0.1:3065/v1`（任何 OpenAI 兼容端点都行） |

## 1. 服务器侧

1. numen + ysm 两个 jar 丢 `server/mods/`，重启服务器。
2. 验证：启动日志有 numen heartbeat；同伴首次进服后 `world/data/numen_companions.dat` 出现（同伴持久化，~225B 起）。
3. 服务器侧 `config/numen/` **不存在是正常的**——大脑不在服务器（0.1.4.1 实锤，别按 master 源码找）。

## 2. 客户端侧

1. numen + ysm 两个 jar 丢版本目录 `mods/`。
2. 用 PCL 正常启动一次（**首启陷阱**：若手工拼启动命令，PCL 导出的命令里有掩码——
   `C:\Users\*************` 和 uuid 掩码 `00000**********************0A328` 带星号，
   正则 `[0-9a-f]*` 匹配不到星号，直接崩 `Invalid UUID string`。
   修法=**字面量替换**成真实用户名和 uuid。见 scripts/launch-client.py）。
3. 验证：进世界后按 G 能开 numen 面板。

## 3. 模型档案（providers.json）

1. G 面板 → 设置 → 模型配置，填：名称 / provider=vllm / model / base_url / api_key / ctx。
2. 点「检测」→ 绿「连接成功，模型响应正常」。
3. **坑：点保存没反应** —— 名称（必填）空着时 `save()` 第一行静默 return，
   名称框在表单顶部容易滚出视野。填上名称再存。
4. 落盘形态：`config/numen/providers.json` 单文件，**api_key 明文在条目里**（0.1.4.1 没有钥匙串拆分）：
   ```json
   {"entries":[{"id":"prov_xxx_0","name":"deepdeep","provider":"vllm",
     "model":"deepseek-v4.1-flash","api_key":"sk-...","base_url":"http://127.0.0.1:3065/v1",
     "reasoning_effort":"off","ctx":200000}]}
   ```
5. **写盘不热生效**（JsonLibrary 单例构造时 load 一次）——改文件必须重启客户端；面板里改保存即时生效。

## 4. 人设（persona/）

1. 平铺单文件：`config/numen/persona/<名字>.md`（模板见 configs/persona-鱼鱼.md）。
2. 重开 G 面板，人设列表里出现（列表刷新靠重开面板，不用重启）。
3. 内置五只（团子/小焰/暖暖/老墨/阿光）带 `.init` 标记，别删标记文件。

## 5. 皮肤（skin.json，MineSkin 预签名免重签）

1. 来源：外星仔 `etlan_fish/figures/fatfish/figure.json` 自带现成 MineSkin 签名三件套：
   `skin_value`（base64 贴图）+ `skin_sig`（签名）+ `skin_variant`（classic）。
2. 构造 `config/numen/skin.json`（模板见 configs/skin.sample.json）：
   ```json
   {"enabled":true,"entries":[{"id":"skin_fatfish01","name":"蓝色大肥鱼",
     "variant":"classic","value":"<skin_value>","signature":"<skin_sig>"}]}
   ```
3. 原图拷到 `config/numen/skins/<id>.png`。
4. **重启客户端** → 编辑卡选上即上身（JsonLibrary 热加载规则同上）。

## 6. 添加伙伴 + 绑定 + 目标

1. G 面板 → 添加伙伴 → 世界里出现同伴实体。
2. 编辑卡（左栏选会话 → 右上 ⋮ → 铅笔；**点大头像=选皮肤卡**）绑定：人设/皮肤/模式/模型配置。
   编辑卡保存=运行中 rebind，即时生效（`bindingChanged()`），不用重启。
3. **`/goal <目标文案>` 只能输在 G 面板聊天输入框**——原版聊天框(T)输会发给服务器报
   「未知或不完整的命令」（/goal 是客户端命令，不在原版命令表）。
4. 目标落盘 `companions/<uuid>/goal.json`；设置成功的标志=聊天面板顶部常驻「目标」条，
   checklist 会随她干活逐项打勾。
5. 目标文案写法（实测有效的句式）：
   - 编号步骤（1 石质工具+工作台熔炉；2 天黑前盖封门小屋放床和箱；…）
   - 「每步一句话汇报」→ 她会真的简短播报
   - 「主人吩咐优先」→ 主人在面板说的话优先级高于目标
   - 「夜里待屋，血低先吃或撤退」→ 夜间/低血行为闸

## 7. YSM 换装（可选）

1. 模型文件放客户端 `ysm/` 目录（14MB .ysm，**不进 git 仓**，license All Right Reserved）。
2. 同伴可换范围=主人授权模型（OwnerSync 同步），不用拷文件给她。
3. 给她递话（G 面板）：`不用走命令，直接调 ysm.model.switch("DS鲸鱼娘flash.ysm")`。
4. 实测她一次成功，服务器日志铁证：`[YSM] Set 'DS鲸鱼娘flash.ysm' models for player 'Feiyu'`。
5. 坑：她可能先试 `/ysm model`（bad_argument）或 `/ysm ping`（卡同意闸
   `numen-consent ask`）——直接把 Lua 调用原文发她最快。
